# Tools

These scripts are development tools, not part of the runtime.

## Asset preparation

```bash
python tools/prepare_assets.py
```

- Extracts the selected files from `Metroidvania Library Asset Pack.zip`.
- Copies the selected 0x72 DungeonTileset II sprites from `tools/vendor/0x72.zip`.
- Downloads the small CC0 Kenney UI sounds.
- Generates the ghost floor shadow, the silent reader creature, the lectern,
  the night window, Rage Book covers and paper-diorama props/FX.
- Writes `docs/ASSET_MANIFEST.md`.

Whesper's approved **A4** sprite sheet is generated separately:

```bash
python tools/make_whesper.py
```

It writes `public/assets/chars/ghost.png` (15 frames: 6 idle, 4 move,
4 cast, 1 hurt) and the previews under `screenshots/`. `prepare_assets.py`
intentionally does not overwrite it.

The three battle manifestations are original left-facing sprites drawn by:

```bash
python tools/make_enemies.py
```

Each is a four-frame sheet in the 0x72 palette (Ink Imp 16×16, Whisper Wraith
16×20, The Last Page 32×36). They replace the front-facing 0x72 sprites, whose
eyes could never be turned toward the player without redrawing. `--preview`
writes `screenshots/enemies-preview.png`.

The seated reader is baked as one sprite by:

```bash
python tools/make_reader.py
```

It composites the library armchair with a hooded reader so the two never read
as stacked PNGs. `prepare_assets.py` does not overwrite either tool's output.

**Pixelify Sans** is committed under `public/assets/fonts/` (SIL OFL; see
`OFL.txt`) because KAPLAY loads it as a TTF at runtime. It is not generated by
the script.

The script expects the asset zips to exist. The library ZIP is in the project
root; the 0x72 ZIP is in `tools/vendor/`.

## Audio generation

```bash
python tools/generate_audio.py
```

Generates the original ambient loops and SFX into `public/assets/audio/`.
No runtime synthesis is used.

## Smoke test

```bash
npm run dev
node tools/smoke.mjs
```

Launches installed Chrome headed (so WebGL works reliably for screenshots),
walks through language → name → intro → hub → battle, and saves screenshots to
`screenshots/`. It needs Chrome at the default Windows path or edit `CHROME` in
the script.

## Battle-flow regression

```bash
node tools/logic_flow.mjs
```

Drives the battle using the debug object `window.__libgaleBattle` and checks
that all three books can be sealed and summaries reached. It clears
localStorage first, so do not run it against a save you care about.

Additional headed tests:

- `node tools/name_test.mjs` — uppercase name input and `{name}` propagation.
- `node tools/hub_test.mjs` — page pickups, the silent reader and book intro.
- `node tools/final_visuals.mjs` — language, battle menu/word/pause, settings,
  journal and interlude screenshots.
- `node tools/visuals.mjs` — title, summary, journal, hub and Last Page views.
